# GraphTutor Vue

纯前端 Vue 3 项目：演示登录会载入内置数据，改动保存在浏览器 `localStorage`。

## 技术栈

- Vue 3 + Vite（开发端口 5174）
- Vue Router + Pinia
- Tailwind CSS 3
- Axios + 演示适配器（`src/demo`，拦截接口请求并读写本地数据）

## 启动

```bash
npm install
npm run dev
```

浏览器打开：http://localhost:5174

登录页点 **演示登录**，即可浏览练习、题库、群组、商城等全部页面。

## 功能

| 模块 | 说明 |
|------|------|
| 登录 / 注册页 | 演示登录；GitHub 入口为前端演示，不会跳转真实 OAuth |
| 首页 / 练习 / 考试 / 错题 | 内置题库与作答记录 |
| 知识图谱 / 知识点 | 节点排序；知识点可展开写笔记 |
| 题库 / 题目 / 导入 | 列表、详情、编辑；JSON 导入写入本地 |
| 学习数据 / 推荐 / 学习路径 | 掌握度与推荐路径 |
| 笔记 / 计划 / 打卡 | 标签、进度条、打卡 |
| 好友 / 消息 / 群组 / 社区 | 群组含成员、题库、排行、自习室、作业等 Tab |
| 排行榜 / 成就 / 商城 | 连续学习榜；积分兑换道具 |
| 设置 | 主题偏好；GitHub / 微信绑定状态保存在本机 |
| 管理后台 | 演示角色下可进入用户、报表、角色审批等页 |

## 说明

- 演示数据来自 `src/demo/data/`，运行后的修改存在 `localStorage` 的 `gt_demo_store_v1`。
- 消息发送后会自动回复，并定时刷新会话（无真实 WebSocket）。
- 本仓库是独立前端，不包含、也不依赖 Graphtutor `server`。
